## 촬영 메모

- 인물은 밝게, 배경은 어둡게. 대비가 강할수록 점묘가 또렷합니다.
- 한 사진에 최대 3명. 같은 사진에 함께 나오는 역할은 서로 다른 팀원이 맡습니다.
- 흩어지는 효과(종잇장)는 코드가 넣습니다. 촬영 때는 정지 포즈만 잡으면 됩니다.
- 사진을 넣은 뒤 `?dev` 로 열어 클릭 영역(`data/scenes.js` 의 `spots`)과 흩어지는 영역(`vanish`)을 사진에 맞게 고칩니다.
